# Explicabilidade em Sistemas de Decisão Automatizada

Este repositório contém o notebook desenvolvido como parte de um Trabalho de Conclusão de Curso em Sistemas de Informação, cujo objetivo é propor um manual para orientar equipes de desenvolvimento sobre quais elementos de sistemas de decisão automatizada devem ser documentados e explicados, para quem essas informações devem ser apresentadas e de que forma.

## Estudo de caso

Como aplicação prática, foi utilizado um cenário de concessão de crédito, com a base de dados **South German Credit**, disponibilizada pelo UCI Machine Learning Repository.

O experimento utiliza técnicas de aprendizado de máquina e métodos de explicabilidade para analisar as decisões produzidas pelo modelo e demonstrar formas de apresentar informações sobre seu funcionamento e seus resultados.

## Conteúdo do repositório

- `analise_credito_explicabilidade.ipynb`: notebook Python com o desenvolvimento do estudo de caso, treinamento do modelo e análise das explicações das decisões.
